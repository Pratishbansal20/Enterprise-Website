# Dealer certificates & awards

Save a clear photo or scan of each certificate here with the exact file name
from `src/data/certificates.ts`, for example:

- `century-authorised-dealer-certificate.jpg`
- `greenply-authorised-dealer-certificate.jpg`
- `royale-touche-authorised-dealer-certificate.jpg`
- `merino-authorised-dealer-certificate.jpg`
- `godrej-authorised-dealer-certificate.jpg`
- `ebco-authorised-dealer-certificate.jpg`
- `pidilite-authorised-dealer-certificate.jpg`
- `excel-authorised-dealer-certificate.jpg`
- `king-koil-authorised-dealer-certificate.jpg`

**Awards:** name them `award-1.jpg`, `award-2.jpg`, … and replace the
empty `title` (award name, given by, year) for each in
`src/data/certificates.ts` (or send the details and they'll be filled in).

Only certificates with a picture appear on the live site. Photograph them flat,
in good light, without glare; crop to the certificate edges.
