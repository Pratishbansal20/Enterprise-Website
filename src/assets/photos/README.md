# Real shop photos

Save each photo here with **exactly** the file name below (`.jpg`, `.jpeg`,
`.png` or `.webp`). It then appears on the site automatically, converted to
AVIF/WebP, resized for phones, and lazy-loaded. Until a photo is added, a
plain wood-texture panel shows in its place.

Tips: shoot in daylight, landscape (4:3), phone camera is fine, tidy the shelf
first, no customers' faces without permission. Any size works; bigger than
1600 px wide is wasted.
